Students — date filter & grouping

Two ways to add “filter by registration date” and separate the list by the date each student registered. Same data, same table style — different treatment.

Sample 1 Grouped by date + From–To filter

Students are split into date sections (a header row per registration day, newest first, with a count and a relative label). The filter is a From–To date range — pick a window and the list narrows to registrations inside it.

Sample 2 Registered column + preset chips

A Registered column is added to the flat table (sortable). The filter is a row of preset chips — Today / 7 days / 30 days / Custom (custom reveals a From–To picker). Rows aren’t split into sections; instead a small date pill marks where a new day starts, so it stays a single compact list.
